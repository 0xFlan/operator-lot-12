# Authorized native asset inputs

Populate this tree locally from a legally owned OPERATOR installation before
running the Unity builders. The repository intentionally omits:

- `[AUTHORIZED OPERATOR NATIVE ASSET INPUTS]`
- `[NATIVE MATERIAL PROFILE JSON]` under the expected `SourceMaterials` folders
- `[NATIVE PREFAB AND HIERARCHY RECORDS]`
- `[NATIVE TEXTURES, MESHES, AUDIO, LUT, AND COLLISION DATA]`

Use the checked-in design allowlist and unresolved specifications as the source
of truth. Do not commit the populated tree.
