# Current status

This repository is the source checkpoint for LOT 12 package `0.1.18` and
companion `0.1.16`, prepared against Modded Operations `0.3.29` and bundled
Operator Mod API `0.2.0-alpha.6`.

Static source, compiler, package, scene-authoring, PVE/PVP marker, and
identity-contract reviews pass in the private build workspace. The exact
companion DLL is 434,176 bytes with SHA-256
`A3240FD73A269572A8421B3E8428D899CA4D8B91642691A4161BB7BCE33CD427`.

This checkpoint is not a public binary release. A real host plus separate
remote client must still prove exact content agreement, opposing teams,
movement replication, firearm-specific damage, scoring, round respawn,
restart generation, and clean return. Online PVE needs a separate two-peer
proof. Late join is not supported by the current fixed-roster PVP agreement.

The repository excludes OPERATOR-derived assets and private test evidence.
Older single-process results are useful history but do not promote these
current hashes to runtime-supported status.
